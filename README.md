# البرنامج التدريبي التخصصي: التقاضي عن بُعد والإيداع الإلكتروني ⚖️🏛️

موقع إلكتروني تعريفي وبوستر إعلاني رسمي عالي الدقة، بالتعاون بين **نقابة محامي شمال القاهرة** و**مؤسسة مهندسون من أجل مصر المستدامة**.

---

## 📁 محتويات المشروع:

1. **`index.html`**:
   * الصفحة الرئيسية للموقع التعريفي، مصممة بأعلى معايير الفخامة والوقار لتليق بالسادة المحامين ورجال القضاء.
   * تحتوي على:
     * أسماء السادة أعضاء مجلس نقابة محامي شمال القاهرة برعاية الأستاذ / عمرو محي الدين (نقيب محامي شمال القاهرة).
     * أسماء وبيانات السادة المحاضرين (مستشارين وأساتذة قانون).
     * الجدول الزمني التفصيلي للأيام الستة والمحاور الدقيقة.
     * إطار البرنامج (المواعيد، الشهادات، الفئات المستهدفة، والرسوم الرمزية).
     * عداد تنازلي لموعد بدء البرنامج.
     * زر الحجز والتسجيل المباشر المرتبط برابط الاستمارة الرسمي: `https://forms.cloud.microsoft/r/TMvDpiHkEm`.

2. **`poster.html` + `poster.png` (البوستر الإعلاني "الألاجا")**:
   * بوستر إعلاني فاخر بتصميم كحلي ملكي وذهبي (Navy & Gold).
   * يحتوي على الشعارات الرسمية الثلاثة (نقابة محامي شمال القاهرة، مؤسسة مهندسون، ونقابة المحامين 1912).
   * صندوق خاص ومميز لمجلس النقابة يحل معضلة تكدس الأسماء بتوزيع جمالي وراقي.
   * يتضمن رمز استجابة سريعة (**QR Code**) يحول الزائر مباشرة إلى صفحة الموقع لقراءة التفاصيل والتسجيل.
   * `poster.png`: صورة جاهزة عالية الدقة (High Definition) جاهزة للنشر الفوري على فيسبوك، واتساب، أو الطباعة الورقية.
   * داخل `poster.html`: شريط تحكم علوي يتيح لك تغيير رابط الـ QR وحفظ البوستر كصورة PNG فوراً بنقرة زر.

3. **مجلد `assets/`**:
   * `css/style.css`: التصميم وأنماط الألوان والخطوط.
   * `js/main.js`: تفاعلات الموقع، العداد التنازلي، وتجاوب القوائم.
   * `images/`: الشعارات الرسمية ورمز الـ QR.

---

## 🚀 كيفية رفع الموقع على GitHub Pages في دقيقتين:

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub (مثلاً باسم: `litigation-training`).
2. ارفع جميع ملفات هذا المجلد (`index.html`, `poster.html`, ومجلد `assets/`).
3. من صفحة المستودع على GitHub:
   * ادخل إلى **Settings** ⚙️.
   * اختر من القائمة الجانبية **Pages**.
   * من خانة **Build and deployment**، اختر الفرع **`main`** ثم اضغط **Save**.
4. ستحصل فوراً على رابط موقعك، مثل:
   ```
   https://[YOUR_USERNAME].github.io/litigation-training/
   ```
5. لتحديث الـ QR Code في البوستر بالرابط الجديد لموقعك:
   * افتح ملف `poster.html` في متصفحك.
   * الصق رابط موقعك في الخانة العلوية، واضغط **تحديث الـ QR** ثم **تحميل البوستر PNG**.
